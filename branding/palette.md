# Nadi Palette

## Primary

| Name | Hex | Usage |
|------|-----|-------|
| **Ink** | `#1a1a1a` | Primary text, headlines |
| **Bone** | `#f5efe4` | Page background (warm cream, not beige) |
| **Clay** | `#c2663a` | Primary accent (Guardian, key CTAs) — a warm terracotta, not neon |

## Neutral ramp

| Name | Hex | Usage |
|------|-----|-------|
| **Paper** | `#fbf7ee` | Card background |
| **Fog** | `#e5ddc8` | Borders, subtle dividers |
| **Stone** | `#8a8275` | Secondary text, meta labels |
| **Ash** | `#4a4641` | Body text on paper |

## Agent identity colors

Each agent has a subtle identifying accent — used only in the deliberation view. The colors are low-saturation so they do not compete with content.

| Agent | Hex | Reason |
|-------|-----|--------|
| **Planner** | `#6b8e7f` | Sage — "think" |
| **Executor** | `#8a6ea3` | Plum — "gather" |
| **Critic** | `#b58755` | Sand — "question" |
| **Guardian** | `#c2663a` | Clay (primary accent — because Guardian is the most important role) |

## Usage rules

- **Never** use `#c2663a` for anything other than Guardian-related elements and primary CTAs. It is the "important" color.
- **Never** use pure white `#ffffff` for background. The bone `#f5efe4` is the paper. Pure white makes the health product feel clinical and cold.
- **Never** use pure black `#000000` for text. Use `#1a1a1a` (ink). Pure black is harsh.
- Agent colors appear only in the Agent Team page. The Home and History pages use only the neutral ramp + ink + clay.

## Contrast

- Ink on Bone: 14.4:1 (AAA)
- Clay on Bone: 5.1:1 (AA)
- Stone on Paper: 4.9:1 (AA)
