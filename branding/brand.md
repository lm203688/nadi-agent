# Nadi Brand Assets

## Logo

See [`logo.svg`](logo.svg). The mark is a stylized "pulse" glyph: a single horizontal line with four rising-and-falling nodes, each node a different weight, suggesting four distinct voices.

## Wordmark

**Nadi** — rendered in the Inter or Fraunces display face, with a 0.2em letter-spacing on the display size.

## Palette

See [`palette.md`](palette.md).

## Tagline

> A team of AI agents that think out loud before they advise you on health.

Arabic translation (for deck courtesy, not primary):

> فريقٌ من وكلاء الذكاء الاصطناعي يفكّرون بصوت عالٍ قبل أن ينصحوك بشأن صحتك.

## Voice and tone

- **Serious, not playful.** Nadi is a health product. It is not trying to be funny.
- **Confident, not clinical.** Nadi speaks plainly, not in medical jargon.
- **Visible, not hidden.** When Nadi's agents deliberate, the user should see it.
- **Short, not wordy.** Every UI string is ≤ 12 words. Every pitch line is ≤ 20 words.

## Do not use

- Cartoon avatars for the four agents. The agents are not characters. They are voices.
- Green health-checkmark icons. Nadi is not a fitness brand.
- Purple/blue gradient backgrounds (AI-default). Nadi's palette is intentionally warm-neutral.
- Any imagery of an earbud, stethoscope, DNA helix, or brain. Those are default health-AI tropes. Nadi avoids them.
